moonbitstack · Apache-2.0

One tree. Every way of writing it.

The JSON family for MoonBit: strict JSON, JSONC, JSON5 and JSON Lines over core's Json, with JSON Pointer, JSON Patch and Merge Patch. A number keeps the digits it was written with, members keep their order, and a failure names the line and the column.

One set of verbs across the family

The s is on the form that takes or answers a string. The plural set exists exactly where the format defines a stream — lines is a stream and has only those; the others define one document and have only the singular set.

the packages

A tree, and every dialect that reads and writes one

One tree, and a package for each way of writing it. The text dialects have the same four faces; the binary formats have the two that take bytes. Writing is always strict JSON, whatever the document was written in.

json RFC 8259

JSON, exactly. No comments, no trailing comma, no leading zero.

 jsonc what VS Code accepts

JSON with comments and trailing commas — the settings-file dialect.

 json5 spec.json5.org

Unquoted names, single quotes, hexadecimal, Infinity.

 lines jsonlines.org

JSON Lines / NDJSON: one document to a line, appended safely.

 pointer RFC 6901

One place in a document, named — with escapes that undo in order.

 patch RFC 6902

Six operations applied in order, or — if one fails — not at all.

 merge RFC 7396

A patch that looks like the document; a null takes a member away.

 path RFC 9535

A query language over the tree: segments, slices, filters, and five functions.

 jcs RFC 8785

One document, one sequence of bytes — what a signature is taken over.

 cbor RFC 8949

The binary encoding JSON's own working group wrote, read and written byte for byte.

 msgpack msgpack.org

Short headers, byte strings, extension types; every format in the specification.

 bson bsonspec.org

What MongoDB stores: ObjectId, dates, decimal128, timestamps, the lot.

 moonjson the shared core

The scanner the dialects share, the writer, and one Refused for the family.
why one tree

Three promises the whole family is built on

01

A number keeps its text

A document read and written again comes back unchanged — including a twenty-digit integer and 1e400, which a double cannot hold and a parser that goes through one silently rewrites.

02

Members keep their order

The order a document was written in is information. A diff is a reason to discard it, and a diff can ask — dumps(sort=true).

03

A failure says where

Reading raises Refused with the offset, the line and the column. An error a person cannot find in their file is half an error.
