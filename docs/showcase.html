One tree, every notation

Everything below is this library compiled to JavaScript — the same code the tests run, in the browser. The document is read as the dialect you pick, so a trailing comma and a // comment are refused by JSON with the line and the column, and accepted by JSON5 — and the sentence you see is Refused::message, printed by the library, not written by this page.
