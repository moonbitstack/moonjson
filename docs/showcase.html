showcase

One tree, every notation

Every notation carries the same tree, so a document written one way reads back the same written another. Pick a notation to see the document that way. The binary bytes are the library's real output, printed by moon run src/examples/showcase.

formatter

Lay it out your way

The formatter applies the same rules as @pretty: an indent in spaces, or one tab a level, names sorted, and every character above U+007E escaped as ASCII. Edit the document on the left; the right redraws.
